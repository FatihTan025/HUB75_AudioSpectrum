# HUB75 Audio Spectrum

STM32F446 + HUB75 LED panel muzik gorsellestirici.

| Klasor | Icerik |
|---|---|
| `Core/`, `Drivers/`, `*.ioc` | STM32CubeIDE firmware projesi |
| `ESP32/SpektrumKopru/` | ESP32 Wi-Fi + Bluetooth kopru (Arduino IDE) |
| `PC/` | PC ayar araci (Python) |
| `Android/` | Android uygulamasi (Kotlin + Compose) |

Ayrintilar ve kararlar: `NOTLAR.md`.

**Android APK:** `Android/` degisince GitHub otomatik derler; **Releases > son-apk > Spektrum.apk**.
